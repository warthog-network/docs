# Libraries

We provide official SDKs that simplify interaction with the Warthog
ecosystem. Both target the **testnet** (`core/defi`) API and implement
the full set of 7 DeFi transaction types. They share the same on-wire
format but are maintained independently.

| Library | Language | Status | Reference |
|---|---|---|---|
| [`warthog-ts`](libraries/typescript.md) | TypeScript | Published on npm as `warthog-ts` | [GitHub](https://github.com/warthog-network/warthog-ts) |
| [`warthog_ex`](libraries/elixir.md) | Elixir | Loaded from GitHub (not yet on Hex.pm) | [GitHub](https://github.com/warthog-network/warthog_ex) |
