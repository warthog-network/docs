Use `#FDB913` as the dominant accent (logos, links, headers, callouts). It is the same color used in the website, the wallet, the explorer, and the whitepaper.

## Font

The Warthog brand uses **Montserrat** for everything — both titles and text blocks. The `brand-kit/fonts/Montserrat.zip` file contains the full family.

| Use | Weight |
|-----|--------|
| Titles | Montserrat Bold |
| Text blocks | Montserrat (regular / family) |

If Montserrat is not available, fall back to a similar geometric sans (e.g., `Inter`, `Nunito Sans`) — do not substitute a serif or display face.
